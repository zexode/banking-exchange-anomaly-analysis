# Исследование банковских и биржевых данных

Курсовой проект по теме «Исследование банковских и биржевых данных для обнаружения аномалий и паттернов финансовых транзакций».

## Подготовленные этапы

- `docs/2_1_project_goals.md` — бизнес-цели, критерии, объект, предмет, аналитическая гипотеза и границы исследования.
- `docs/2_2_sources.md` — выбор источников и характеристик по пунктам 2.2 и 3 методички.
- `docs/2_3_data_preparation.md` — предварительный анализ, очистка, описание полей, шкалы, интеграция, хранение и текущий статус данных по пунктам 2.3–5.
- `notebooks/2_2_data_understanding.ipynb` — каталог источников.
- `notebooks/2_3_data_preparation.ipynb` — воспроизводимая подготовка данных и отчёт с результатами.
- `src/prepare_stage_2_3.py` — загрузка, очистка, профилирование, разметка текста, TF-IDF, объединение и обновление данных.
- `data/raw/laramee26openBankTransactionData.xlsx` — исходный банковский набор MoneyData.

## Запуск этапа 2.3

Нужен Python 3.10 или новее. Скрипт использует стандартную библиотеку Python; сторонние библиотеки для чтения XLSX, API, XML и TF-IDF не требуются.

```bash
python src/prepare_stage_2_3.py
python src/prepare_stage_2_3.py --download
python src/prepare_stage_2_3.py --refresh
```

Первый запуск обрабатывает уже имеющийся XLSX и пересобирает локальные выходы. `--download` загружает отсутствующие JSON-ответы Binance и архивы новостей. Чтобы SEC разрешил загрузку XML, задайте `SEC_CONTACT_INFO` с названием проекта и настоящим контактным адресом. При ошибке проверки сертификата попробуйте другую доверенную сеть; проверку TLS не отключайте. Файлы и результаты формируются под `data/raw/` и `data/processed/`.

## Текущая доступность источников

Последний локальный запуск обработал MoneyData (6 567 операций, 2015-01-09 — 2022-12-07) и корпус финансовых новостей (41 910 статей за 2021–2022 годы). Для новостей построена разреженная TF-IDF матрица на 500 признаках. Binance и SEC пока не загрузились из-за ошибок TLS в сети компьютера; поэтому интегрированная месячная таблица пока пуста. Повторный запуск обновит профили по имеющимся файлам.

Обработанные файлы исключены из Git согласно `.gitignore`; исходный открытый банковский XLSX включён в проект вместе с атрибуцией. Новости и ответы внешних сервисов пользователь может получить повторным запуском загрузки.
