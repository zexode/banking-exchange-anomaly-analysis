# Используемые источники

Состав, признаки, лицензии и ограничения описаны в [`docs/2_2_sources.md`](../docs/2_2_sources.md).

- Банковский XLSX MoneyData размещён локально в `data/raw/` и лицензирован CC BY 4.0.
- SEC XBRL instance XML и Binance Spot JSON API — официальные источники, используемые как внешние рыночные/банковские факторы.
- Финансовые новости представлены текстовым корпусом с метаданными; лицензия CC BY-NC-SA 4.0.
- Kaggle допустим как платформа-источник только после проверки конкретного набора и его лицензии; отдельный набор Kaggle сейчас не выбран.

На этапе 2.2 выполняется каталогизация и обоснование. Загрузка внешних наборов, очистка, проверка пропусков, аннотирование и объединение отнесены к пункту 2.3.
